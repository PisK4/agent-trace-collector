# Agent Note: 方向 A 对齐修正与头部可读性

Status: implemented

## Problem

2026-11-02，Pis 指出会话头左右字段不齐，右侧条目被压缩。对照方向 A 细节设计稿的 r1–r8，在 master `3d791eb` 上确认 22 项实现与交互缺口，另有会话笔数和列表摘要两项已记录的主动偏离。角色辨识继续使用用户选定的甲方案。

头部两列独立纵向排列，没有共享行高。1895px 合成页中，左行约 18.70px，右侧工具行 22.5px；第二行起点差约 3.80px。加入八个 Skill 后，nowrap 流又把 Bash 名称从约 25px 压到 5px，次数 103 从约 19px 压到 4px。按需说明虽然生成在行下方，却被行本身的 overflow:hidden 裁掉。

本记录部分取代[会话头双列](../feature/2026-11-01-session-header-two-column.md)的严格单行与允许 chip 收缩取舍，部分取代[第 3 步](../feature/2026-11-02-direction-a-step3-sessions-topbar.md)的会话行、logo 与面包屑取舍，并补充[第 4 步](../feature/2026-11-02-direction-a-step4-header-denoise.md)的路径辨识、[第 5 步](../feature/2026-11-02-direction-a-step5-tools-pair-page.md)的列表读数和[第 6 步](../feature/2026-11-02-direction-a-step6-treemap-monochrome.md)的数值密度。它们的其余决策继续有效。摘要字段来源和查询成本由[汇总条目补执行段与已有参数摘要](2026-11-02-summary-entry-exec-and-arg.md)持有。

## Decision

头部优先保留当前可见条目的名称、次数和失败事实。左右共享三条行轨道，按资源／性能／结构对应工具与 Skill／写入／读取；右侧换行或清单展开时，同一轨道两侧一起增高。宽度不足仍按中栏容器切成单列。前三工具和前三路径后的 +N 保留；名称可单独省略，次数与失败数不参与收缩。

写入、读取保留两个字的前缀。统计读数用 mono，中文标签继续使用 UI 字体。文本截断留在文本节点，说明浮层不再被其容器裁切。+N 复用现有 folds，键包含会话与分组，结构重绘同时恢复 open-wrap；吸顶让位继续跟随头部实际高度。

其余修正按走查范围收敛到现有展示模块：

- H1–H7 对应上述顺序、共享轨道、收缩、前缀、字体、说明与开合恢复。
- R1–R3：请求结构头部给新增数；消息按序号、角色、预览排列；纯结果块按实际内容判定，用较弱的 mono。续读、缺口与失败入口保留。
- C1–C2：上下文大数字用 mono；树图仅份额前四名且尺寸足够的块显示数值。四是展示预算，单色份额档位不变，每块完整 aria 与 title 保留。
- T1–T3：正常耗时弱灰，读数槽去角色底色；工具调用 mono、名字加重、结果再弱一档。耗时阈值与等待工具豁免不变。
- B1–B2：logo 用中性主干与两枚中性节点、蓝色分支点；面包屑先给请求位置，后给可省略的标题。
- S1–S2：会话栏常驻已加载数量；笔数与 agent 回到第二行，时间靠右；加载更多放列表末尾。响应没有全库总数，不补造分母。
- P1–P2：列表失败数单独红字，列表与配对页展示有来源的执行窗口，缺值留空。条目摘要优先；无摘要时同步复用已缓存 detail/meta，同一请求只在本次目录渲染中解析一次，不新增读取或持久缓存。
- U1：刷新、回到开头／最新和返回动作局部 ghost 化，不修改全局 chip-btn。

## Alternatives considered

**只加宽右列或缩小字号。** 独立行轨道仍会错位，Skill 增多仍会压掉计数；固定字号，把行高和换行关系表达出来。

**继续强制单行。** 头部更低，但合成高密度场景已证明数字和失败事实一起被省略。接受换行造成的高度增长。

**把工具和路径全部默认展开。** 设计稿保留前三 +N，全部展开会持续占用正文空间；继续按需展开，并修复刷新与会话隔离。

**把会话笔数留在标题行。** 250px 会话栏内，标题、笔数、时间竞争同一行；恢复设计稿第二行位置，让标题独占一行。

**为每条摘要请求正文。** 目录上限 1000 条，额外网络与解压成本不值得。沿用有界查询和已缓存证据；缺值仍保留调用序号。

**按 r8 批量改灰所有页签。** 设计稿的底部阅读分片没有明确对应当前轮次带或右栏页签，修改对象不确定。本轮保留这些选中态。

## Consequences

右侧密集 chip 换行时左侧会出现留白，这是共享行轨道和保留完整计数的代价。极窄中栏的左侧统计仍可能整体尾部省略；本轮没有把它改成多行统计。前三以外条目仍需展开，折叠记忆只在当前页面会话内保留，不承诺整页 reload 或跨设备持久化。

执行窗口包含客户端处理、人工确认和中断等等待，不能当成工具进程精确运行时间。无既有摘要且正文未缓存时，目录行仍只有调用序号。数据库 schema、派生版本与正文读取预算不变。

实现由两个 Sub-Agent 分别完成前端和目录数据，主 Agent 复核与统一验收。合成测试、浏览器尺寸和未覆盖项记录在[合成验收](../../../../docs/acceptance.md#方向-a-界面对齐修正合成2026-11-02)，步骤见[实施计划](../../../../docs/superpowers/plans/2026-11-02-direction-a-alignment.md)。用户于 2026-11-02 显式授权提交、`--no-ff` 合并并重启生产服务；真实流量结果单独记录在[生产验收](../../../../docs/acceptance.md#方向-a-界面对齐修正生产2026-11-02)，合成结果不替代生产结果。
