# Agent Note: 切窗收尾服从较新的阅读选择

Status: implemented

## Problem

窗口外请求的切窗动作等待窗口列表时，用户可能切换会话或选择另一条步骤。旧动作完成后继续定位原目标，会把旧会话请求写进新会话，或覆盖期间的新选择。主动定位安排到动画帧后，等待期间用户也可能已经移动视口。

## Decision

切窗收尾同时检查导航代次与选择代次。窗口重建期间出现新的请求选择时保留它；若选择落在新窗口外，按窗口外请求显示。初始 URL 目标的异步解析也检查请求与代次，避免迟到响应覆盖新选择。

主动滚动在调度时捕获当前导航、选择与滚动位置，动画帧执行前检查它们仍然有效。它只保护本次定位，不在整场会话里记录用户是否曾经移动。窗口准备期间的定位立即完成，使目标可被后续键控提交锚住；准备完成后仍按原规则平滑定位。键控提交的同步锚点补偿仍负责布局变化，见[中栏键控提交与视口锚点](../architecture/2026-10-27-keyed-trace-main-view.md)。

本决策补充[页面读取缓存收拢进 reader-store](../architecture/2026-10-24-page-cache-single-home.md)的导航代次：代次不仅覆盖窗口列表的 await，也覆盖切窗动作自己的后续定位与动画帧。

## Alternatives considered

**使用整场会话的用户已移动闩锁。** 它会让一次滚动永久阻止之后有意发起的定位；本次定位检查自己的短期上下文。

**把异步定位并入同步锚点补偿。** 两者的目的不同：锚点补偿保持原位置，显式定位把目标带入视口。继续由提交层处理同步补偿，延迟定位自行验证资格。

**切窗完成后总选原目标。** 会覆盖切窗在途期间明确发生的新选择，并可能跨会话带入旧请求。保留较新的选择。

## Consequences

切窗、换会话与用户选择交错时，旧目标不再覆盖新选择；目标不在新窗口时仍可在右栏阅读。代价是新选择可能落在窗口外，完整轨迹需要再次切窗。动画帧执行前滚动位置若已变化，放弃该次自动居中；后续显式定位仍可执行。

## Testing

合成浏览器延迟窗口列表复现跨会话污染与切窗覆盖新选择；延迟动画帧复现滚动后被拉回。自然时序下动画帧窗口未命中。修复后的复测结果单独记录在[验收记录](../../../../docs/acceptance.md)；真实流量未作为合成验收的替代。
