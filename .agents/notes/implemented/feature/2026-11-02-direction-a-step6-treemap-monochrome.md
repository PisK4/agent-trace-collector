# Agent Note: 方向 A 第 6 步——树图单色化与新增横幅退役

Status: implemented

## Problem

[方向 A 重制提案](../../proposed/feature/2026-11-02-frontend-direction-a-restyle.md)第 6 步：用量树图七个类别各占一个色相（`--p1..p7`），同屏红橙绿蓝紫齐出；「新增 N 条消息」在右栏以纯计数横幅占一行，消息列表里又逐行「新增」文字标签，同一事实说三遍。

## Decision

- **类别色退役，份额四档上岗**：`partColor`/`partSlot` 与 PARTS 的 `slot` 字段删除；新增 `partShade(tokens, sum)` 按占提示总量的比例落 `--t1..t4` 四档单色（浅 rgba(0,122,255,.16/.12/.08/.05)，深 rgba(10,132,255,.18/.13/.08/.04)，样张原值）。阈值 ≥15% / ≥7% / ≥3% 是示意值（提案 Risk 已预告），真实会话验证深色区分度后可调，判据只在 parts.js 一处。未知 kind 与已知同口径按份额落档，不再有独立灰槽。
- **tile 上色方式随之改变**：底色从「类别色 color-mix 16%」改为直接铺 rgba 档位色——档位色已含 alpha，再 mix 会二次稀释；边框固定 accent 14% 混 line，hover 固定 accent 24% 混 surface 加 accent 边（不再随类别色变化）。
- **全部类别色点删除**：构成图例色块（`.comp-legend .sw`）、明细行类别点（`.ctx-row .dot`）、明细浮层头类别点（`.ctx-d-head .dot`）一并删除。只改树图不改图例会留下「彩点对应不上任何东西」的断裂，所以色点三处一次删齐；类别归属由行名与点击行为承担。明细行的份额条改 `--t2`，与树图同一视觉语言。
- **「新增 N」纯计数横幅删除**：增量全部消费完（done）与 delta 空集两个无交互的态不再渲染 note——空集场景旧渲染会说出「新增 0 条消息」。带交互的两态保留：未消费完的「继续读取」与失败的「重试续读」。
- **行级「新增」文字标签改蓝缘**：`.msg.msg-new` 行左缘 2px accent（复用 `.msg-head` 既有的透明左缘占位，零布局位移），「新增」span 删除，aria-label 补「，新增消息」保键盘与读屏可达。与选中态同语言但可区分：选中 = 蓝缘 + 浅蓝底，新增 = 仅蓝缘。

## Alternatives considered

- **按排名取档**（第 1 名 t1、第 2-3 名 t2…）：样张的 12% 与 8% 同档说明作者意图是份额而非名次；份额阈值对「两类同大」与「长尾一片」都给出稳定结果，排名制会在名次跳动时整块变色。
- **明细行份额条也删**：条与旁边数值重复表达份额，但它是行间扫读的锚点，保留成本低；单色化后不再有「颜色分类」的额外信息，退化为一根普通数据条。
- **「新增」文字保留、只加蓝缘**：同一行的双标记互相重复；蓝缘已有选中态先例，语言一致。

## Testing

- `bun run typecheck` 通过；`tests/web.test.ts` + `tests/body-view.test.ts` + `tests/context-map.test.ts` 共 92 用例全过。partShade 阈值边界钉住（.15/.07/.03 归高档、总量 0 不除零）；done 与 delta 空集断言改为不出横幅；pending 与失败两态的续读入口断言原样通过。
- 合成页目测（`/tmp/atc-restyle/step6-treemap-{light,dark}.png`、`step6-msg-new-light.png`）：浅色四档 19 块全落 .16/.12/.08/.05；深色四档 .18/.13/.08/.04 区分度可辨（30% 大块明显实于 3% 小块）；消息列表 #4/#5 蓝缘可见、无标签无横幅。
- DOM 检查：`.ctx-row .dot`、`.comp-legend .sw`、`.ctx-d-head .dot` 全部为 0，`--p1` 变量不存在，`--t1` 生效。

## Consequences

- **类别颜色辨识消失**：扫读树图分辨「这是文件还是对话」从颜色改靠块内文字与点击后的明细；多类别小块并排时需要一次点击确认，是「不再用颜色分类」的直接代价。
- **阈值待真实数据校准**：合成数据的份额分布不代表生产；若真实会话出现大片同档，调 parts.js 的三个阈值即可，不动结构。
- **新增蓝缘在长列表里逐行出现**：新增多时一列蓝缘；这继承了旧「新增」标签逐行出现的密度，但视觉重量更低。
