# Agent Note: 右栏请求上下文与工具详情

Status: implemented

## Problem

Task 6 交付的右栏是过渡形态：读数页只有用量/计时/上下文组成/身份完整性，请求能力与请求结构只在主栏步骤详情里出现；工具详情没有独立页面，配对状态、结果正文加载状态与 is_error 三态混在一行文字里；Schema 没有入口，能力清单的开合在重绘后丢失；正文页签在结构从未读取时拿不到「加载下一片」按钮。

## Decision

读数页的区块组成（能力/结构/回复/上下文/身份完整性与结构懒加载）由本篇确立；排序、默认折叠与用量位置后经[读数条与「无则不显」收敛](../../simplification/2026-10-24-rail-usage-strip-and-absence-hiding.md)重排（回复优先、用量与计时上移头部读数条），以该篇为准。结构折叠未读取时用元信息页 total 显示数量（「45 条消息」），首次展开才 `loadStructure`（40+5 分页），列表只列 `structure.ords` 连续区间，delta 定点读到的消息不混进历史；delta 为空集显示「新增 0」，关系未确认显示派生关系说明并不标新增；点开消息详情与返回只动 `structure.selected`，计数不变。回复完整性按 §3.4 标注（finish=length/max_tokens 为截断，请求状态仍成功；缺失回复不标完成），异常态显示在回复折叠行摘要，正常态不带标签；推理块保持折叠。

工具页签：未选中时列出全部调用，选中后是概览/参数/结果/Schema 四页，返回按钮回列表；调用列表的正常态标记（配对、正文加载）后经[读数条与「无则不显」收敛](../../simplification/2026-10-24-rail-usage-strip-and-absence-hiding.md)删除，异常（多候选）才挂 chip。概览把配对状态与正文加载状态分立，resolved 不写成成功，模型时长归属请求、工具执行时长未采集；结果页用 Task 3 的按调用位置读取接口，未读取显示「待读取」并提供读取与「查看承载结果的请求 N」（N 为窗口展示号）两个入口，读取失败保留重试，pending/ambiguous/unpaired 不显示正文；409 清掉旧关联展示并整笔重建。参数页展示原始 inputText 并复制原文；Schema 页只读当前元信息页的能力视图：0 项时按能力状态区分「未声明」「未携带」「缺失」「未读完」「格式未识别」，同名多定义逐项列出并说明无法唯一选择，不任选第一项。

状态恢复：所有折叠（能力清单、条目 Schema、结构、回复内推理块与工具往返、上下文组成、内联详情的披露区）按稳定键（cap:tools、cap:tool:<name>、structure:<req>、route:<req>、reply/think/round/prompt:<req> 等）存 folds 表，`renderMain`/`renderRail` 后统一恢复 open 属性，无记录的键保留 markup 默认开合；路由改懒读取（展开或切页签才 `readRoute`，不在渲染时预取）；右栏滚动只在「同请求同页签的重绘」里保持，页签切换与换请求归顶（旧实现跨页签保留位置会被短页面夹到 0，行为不可预期，改为确定性语义）。

## Alternatives considered

**能力/结构保持主栏内联不进读数页。** §1.3 明确读数页先显示这三节；主栏步骤详情保留内联版本，两处共用同一份读取缓存。

**折叠开合只靠 DOM details 天然状态。** innerHTML 重绘会把用户展开的清单收回；按 details 下标恢复又会恢复到另一份清单，稳定键是唯一不串位的方案。

**工具结果自动预读所有 resolved 调用。** resolved 不等于要看正文；只有打开详情/结果页或点入口才发起一次读取，失败不重写关联状态。

## Consequences

右栏四页签（读数/正文/工具/路由）齐备，正文页签在结构未读时也能发起首次结构读取（用元信息 total 判断未读）。验证：`bun test`（八文件 136 例全过，新增读数页顺序/结构折叠/回复完整性四态/Schema 五态/同名多定义/工具结果面板七态/is_error 三态/工具 409 与迟到结果等用例）与 `bun run typecheck` 通过；合成浏览器验收（2026-10-24，端口 8770 合成服务补 45 条消息深样本 119 与 /route 端点）：读数页顺序与默认全折叠、40+5 分页（40→45）、消息详情返回计数不变、能力开合重绘保持、116 双调用按调用序号取到各自正文、五个 Schema 状态文案各不相同、108/109 截断与成功并存且 101 不标截断、113/104 未确认不给正文与读取入口、路由懒读取、滚动语义（页签切换归顶、同页签重绘保持，内容变短按上限夹取属预期）、400/620/1000/1240px 无横向溢出且工具结果页 pre 内部滚动、剪贴板拒绝不炸、全程无 pageErrors。已知边界：同请求双结果等 409 语义由 reader-store 单测覆盖（合成服务不产生 409）；滚动保持以页签内为界，跨页签回顶部。
