# AGENTS.md — Implemented Agent Notes

这类 Agent Note 描述已交付的决策。遵守[根指令](../../../AGENTS.md)与 [Agent Note 格式](../README.md#the-file-format)；`verify-agent-note-format` 门禁强制生命周期专属结构。

## 保持 implemented Agent Note 与实际交付内容同步

路径、符号、默认值与机制在改动它们的同一个变更中保持最新。原地改写过期事实；不追加变更历史。

当一份已交付的 note 不太可能再指导未来工作时，按[归档规则](../README.md#归档与删除)把整篇文件移入归档区，而不是继续维护它。

### 这不是改写决策的许可证

只更新事实实现。反转决策或决策依据需要一份新 Agent Note 并交叉链接；被完全取代的旧记录只能按 [Agent Note 规则](../README.md#何时需要写一份)的合并条款删除。
