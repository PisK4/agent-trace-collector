# Agent Note: 隐私边界与本地接口防护

Status: implemented

## Problem

trace 库保存的是请求与回复正文，里面有 API key、账号字段、工具参数和用户对话。只监听回环地址不足以保护接口：任意网页也运行在本机浏览器里，DNS rebinding 可以让外部域名解析到 127.0.0.1，magpie 自己就因为这个问题修过。不开 CORS 也不构成浏览器访问边界。测试与仓库还面临另一条泄漏路径：真实请求正文、令牌和用户配置一旦进了 fixture、日志或提交，就脱离本机权限保护。

## Decision

监听地址写死 `127.0.0.1`，不读环境变量覆盖；Host 只接受 `127.0.0.1:<port>` 与 `localhost:<port>`，其余 403。页面 API 限同源，拒绝跨站与 `Origin: null`；不带 Origin 的非浏览器访问走独立规则。hook 认证用独立随机令牌，读令牌、hook 令牌与脱敏盐分文件保存，首次启动自动生成，权限 0600；插件只拿 hook 令牌。认证顺序固定为 Host、精确 Origin、常量时间令牌、来源；`origin=local` 只是来源标签，不是认证。

脱敏在分块之前做。请求头按白名单保留 `content-type` 之类，`authorization`、`x-api-key` 等替换为稳定占位符；已知凭证形态（`sk-`、`Bearer `、`AKIA`、私钥块、JWT 三段式）按模式替换；敏感字段按路径匹配，不用宽泛键名；用户可加正则。占位符同类同值映射一致，正文仍可读，去重也不会因为脱敏变得零碎。字符串里携带的 JSON 也要检查，工具参数常以字符串形式出现。

运行数据不进仓库：数据库、WAL、日志与密钥在数据目录，文件 0600、目录 0700。测试只用合成数据；真实请求正文、账号、令牌和用户配置不复制进 fixture、日志或提交。页面把正文与路由内容一律当文本转义，不直接插 HTML。

实现见 [src/http.ts](../../../../src/http.ts) 与 [src/privacy.ts](../../../../src/privacy.ts)，完整边界见[架构设计的安全边界](../../../../docs/architecture-design.md#安全边界)。

## Alternatives considered

**只绑回环地址，信任本机。** 本机浏览器里的任意网页都能发起请求，DNS rebinding 还能绕开域名与地址的直觉；magpie 自己修过这个问题，说明单靠监听地址不够。

**用 CORS 当访问边界。** 不开 CORS 只约束浏览器的读取，不约束请求到达；同源校验、Host 校验与令牌是三道独立的门，缺一道都会留下可绕的路径。

**读令牌与 hook 令牌共用一个。** 页面只读账本，插件要写 hook；共用令牌会把写权限扩散到前端可见的位置。分成两个文件，插件只拿 hook 令牌。

**按宽泛键名脱敏，凡是含 `key`、`token` 的字段都替换。** 会误伤用量字段（`usage.*`、token 计数），破坏读数；按字段路径匹配，凭证替换、用量保留。

**在分块之后脱敏。** 块哈希会基于未脱敏内容，同一份内容带不带凭证会存成两份；脱敏放在分块之前，哈希基于脱敏后的内容。

## Consequences

- 页面与 hook 都必须带本地令牌；没有令牌的请求在认证层被拒，不会进入解析与写库。
- `Origin: null` 与跨站请求一律拒绝；不带 Origin 的非浏览器访问走独立规则，避免把正常本地工具挡掉。
- 占位符稳定，正文可读且去重稳定；代价是同一凭证在不同请求里映射到同一占位符，不能从占位符反推原值。
- 脱敏规则带版本号，验证集覆盖凭证、数字、工具 schema 与关联 ID 四类；改规则要同时重跑验证集，避免误伤读数。
- 真实数据不进仓库，测试只能用合成数据；代价是合成库覆盖不到真实流量里的形状漂移，真实验收要单独做。
