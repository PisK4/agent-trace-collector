# Agent Note: 轮次身份行与顶栏的再一轮降噪

Status: implemented

## Problem

[前端降噪原则](../process/2026-10-24-frontend-denoise-standing-rule.md)立为常备约束、[顶栏与中栏常挂提示降噪](2026-10-25-topbar-and-trace-hint-denoise.md)清过一轮后，实际使用又暴露四处版面问题：

- 轮次态右栏身份行是「轮 N · 命令 req X · 回复 req Y」。两个请求号是库内主键，读者拿它没有任何可发起的动作：轮次态里没有「跳到那笔请求」的入口，定位实际靠轮次带与点轨迹行。[轮次两端阅读](../feature/2026-10-25-turn-pair-reading.md)写下的「上下文靠请求号手动定位」在带吸顶承担目录后不成立。
- 顶栏「本地库」来源标签不承载信息：当前只有本机一个数据源，prototypes 静态服务同一套页面，来源区分不靠页面上的标签表达。
- 复制会话 ID 的 ⧉ 按钮挂在顶栏右侧操作按钮群里，与作用对象（当前会话）在版面上没有关系，含义要靠 tooltip 补。
- 左栏会话行的「含失败」文字与红点重复：红色是高显著度状态色，点已经把失败说完了。
- 品牌没有交互：回主页只能手动清 URL 参数，且不刷新数据。

## Decision

- 轮次身份行只留「轮 N」，两端请求号从阅读路径上移除。
- 顶栏「本地库」标签删除。
- 复制会话 ID 按钮内联在会话头 facts 行的会话 ID 文本之后：操作对象就是旁边的这串身份，按钮含义由位置自明；会话未选中时不渲染。
- 左栏会话行的「含失败」文字删除，红点承载状态、悬停给字眼；「缺正文」保留文字——它的点刻意低对比，与正常点的差别不可辨，文字是唯一载体。
- 品牌（logo 与 Trace Collector 字样）是按钮，点击回主页并整页刷新：落地为 `location.href = location.pathname`，清掉 URL 参数后按初始态重新加载——重读会话列表、自动选最新会话。

## Alternatives considered

**两端请求号换成窗口序号（如「命令 12 · 回复 21」）。** 序号随「加载更早记录」重排，仍然不可操作；换写法不解决「没有动作可发起」的问题。
**品牌点击用 SPA 方式清状态回首页。** 要在页面里重置选择元组、折叠表、汇总条目视图与在途导航代次，以后每加一个选择字段都要记得同步进重置清单；整页重载一行达到同一可见结果，代价只是本机页面的重新载入。
**复制按钮放在左栏「会话」标题旁。** 首版落点。「会话」是栏目标题，复制的是会话 ID，两者隔着语义距离；用户复核后改为贴着会话 ID 文本，按钮与作用对象零距离。
**失败行只留红点不留任何字眼入口。** 采纳为现状（红点 + 悬停 title）；如果未来红色语义扩散、红点不再唯一指失败，再回到文字标签。

## Consequences

轮次态右栏头部只剩轮号；想知道两端请求号需点轨迹行回请求态——那是能对单笔请求发起动作的地方。顶栏剩品牌、请求定位 crumb 与三个面板按钮；会话 ID 的复制钮随会话头重绘重建，点击走文档级委托。已知代价：品牌点击丢弃当前阅读位置与展开状态，这是「回到主页刷新」的语义本身；左栏失败会话只剩红点，字眼要悬停才可见。验证（2026-10-25）：`bun test tests/turn-band.test.ts tests/web.test.ts`、`bun run typecheck` 通过；提交前跑 `bun run verify:notes --staged`。
