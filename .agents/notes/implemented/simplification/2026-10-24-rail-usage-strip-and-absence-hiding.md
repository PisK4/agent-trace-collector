# Agent Note: 右栏读数条与「无则不显」收敛

Status: implemented

## Problem

右栏读数页长成了三层壳装一条信息：请求能力 section 头套两个折叠卡、本次回复 section 头套回复卡再套推理块折叠；同一信息以三种折叠样式并存。大数字格、用量格、时间构成条形图三处重复（输出速度出现两次，首字与首字前是同一个数），模型名在标题兜底与回复卡头各出现一次。更普遍的问题是「没有」被渲染成提醒：未配对、未定价、未报告、正文待读取都以 chip 或说明段常驻，正常态与异常态在视觉上无法区分，用户扫一眼分不清哪里真的有问题。

## Decision

右栏改为两条显示规则，并把读数页重排。

**规则一：状态提醒只在异常时渲染。** 元素出现 = 异常，或 = 行动入口。正常态不渲染任何元素：工具往返未配对不出 chip；工具页签调用列表去掉「配对已确认 / 正文待读取 / 正文已加载」；费用只在 priced/zero 时显示；「首个文本 未报告」「回复完整」标签删除；身份完整性三条通道全正常时整节不出现（路由历史未关联是当前来源的常态，不算异常）；路由页签单项候选顺序、单次干净尝试链不显示。已配对的工具调用改给「→ 结果 · 04」跳转按钮（行动入口），保留多候选等异常 chip。

**规则二：数值槽位缺位显示「—」，不隐藏。** 隐藏会被读成 0，违背「缺失不当 0」的账本语义；状态词提醒与数据槽位是两类「没有」，切分处理。

**头部读数条（数字后经[计时与用量并入「用量与上下文」折叠行](2026-10-24-usage-ledger-fold.md)移入读数页末位折叠行，头部只留身份行）。** railHead 曾以两行等宽数字条承载模型与计时、用量；数字现全部在读数页末位折叠行。仍然有效：口径解释全部下沉为各数字的 title；用量与时间构成 section 从读数页删除；`model_time` 兜底标题不再渲染为标题行；回复卡头与正文详情的模型名删除——模型全页只显示一次（现为头部身份行）。

**读数页重排。** 顺序改为本次回复 → 请求结构 → 能力清单 → 上下文组成 → 身份完整性（异常时）。本次回复与工具往返默认展开（`data-fold` 无记录时保留 markup 默认值），推理块保持折叠；能力清单、上下文组成统一为 `rail-fold` 折叠行（新稳定键 `reply/think/round/prompt:<req>`），`cap-block`、`msg-thinking`（回复内）、`reply-card` 三种旧样式与 `.rail-big/.u-grid/.meter/.time-bar` 样式删除。能力清单的 empty 状态整行不渲染；上下文组成摘要行给占比前三类。

## Alternatives considered

**保留 section 分组、仅统一折叠样式**：改动小，但「请求能力」section 头对两条信息仍是三层壳，数量被压在头与行两级；平铺折叠行让每个数量在 summary 裸露。落选。

**把推理块 / 工具往返平铺为顶层行（不嵌套在本次回复内）**：扫视更平，但推理与往返语义上属于回复，顶层混排后请求侧与回复侧边界消失；折叠键与状态恢复也要跨请求区分。保持嵌套。

**缺失数值槽位一并隐藏**：更符合「无则不显」的字面，但入/出/缓读的缺位会被读成 0，恰好制造账本语义要防的误读；「—」保留缺失可见性。落选。

**读数条放读数页顶部而非 railHead**：不常驻四个页签，正文/工具页阅读时失去用量上下文；railHead 渲染一次即可，成本相同。落选。

## Consequences

读数页第一眼是一叠「标签 · 数量」折叠行，异常项自带颜色，正常项零噪音；口径句子不再占版面但 hover 可得。代价：正常态「看起来什么都没有」需要用户接受「无提示即正常」的约定；时间构成条形图与缓存命中条删除，时间占比只剩数字；读数页顺序与折叠键变更使「回复完整」标签无处安放——其信息由 finish 摘要（正常时）与异常标签（截断/缺失/无法解析）分担。部分取代[单一轨迹生产阅读](../../architecture/2026-10-23-single-timeline-production-reader.md)与[右栏上下文与工具详情](../../feature/2026-10-24-rail-context-tool-details.md)的读数页排序、默认折叠与 chip 陈述；这两篇中仍然有效的机制（结构懒加载、折叠稳定键恢复、工具四页定位）不受影响。

## Testing

`bun run typecheck` 通过；`bun test` 全量 526 例通过（读数页排序、能力区块、工具往返、回复详情等 7 组用例随新契约更新）；合成与真实数据浏览器验收：头部读数条（含缺值「—」、未定价隐藏）、回复/工具往返默认展开、「→ 结果」跳转到工具结果页、empty 技能清单整行消失、身份完整性仅异常通道、工具页签零正常态 chip。
