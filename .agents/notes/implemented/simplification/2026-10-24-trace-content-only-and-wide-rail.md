# Agent Note: 中栏只呈现内容，详情集中右栏

Status: implemented

## Problem

中栏每行右侧的状态、工具结果入口与展开箭头占用正文宽度，异常记录又把同一句说明显示两次。右栏承载正文和工具详情，进入页面后仍需要手动拖宽。

## Decision

中栏负责浏览步骤，点击步骤后在右栏查看对应正文、工具调用或请求读数。删除中栏重复的附加信息和内联详情路径；异常仍作为独立记录保留，工具结果入口留在右栏。右栏按可用空间默认展开到宽度上限，保留手动调整。布局数值与交互约定见[架构设计](../../../../docs/architecture-design.md#轨迹阅读布局)。

本决定部分取代[步骤投影](../feature/2026-10-24-trace-step-projection.md)的行内附加信息、[布局控制](../feature/2026-10-24-trace-layout-controls.md)的默认宽度，以及[生产阅读](../architecture/2026-10-23-single-timeline-production-reader.md)的中栏详情展示。投影语义、窗口读取、工具关联与布局可访问性仍由各自记录解释，相关记录继续保留。

## Alternatives considered

**只用 CSS 隐藏行右侧。** 隐藏后会留下无入口的内联详情状态与渲染代码，而且历史加载的滚动锚点依赖展开箭头。直接删除并把锚点移到步骤选择按钮，维护成本更低。

**固定右栏始终为宽度上限。** 较窄的桌面窗口会压缩中栏。默认宽度仍经过现有夹取规则，手动缩窄后保留本页选择，双击恢复可用上限。

## Consequences

中栏为内容提供完整行宽，用户消息、助手文本和工具调用通过同一个行入口进入右栏；请求失败与缺失记录各显示一次。中栏内联展开能力移除，阅读完整内容依赖右栏。加载更早记录继续按稳定步骤键补偿滚动位置。宽度只存内存，窗口缩小后再放大能恢复用户选择的宽度。

## Testing

`bun test tests/trace-view.test.ts tests/web.test.ts tests/reader-store.test.ts` 的 34 项测试通过。合成浏览器验收覆盖跨请求选择用户正文、助手回复与工具调用、折叠右栏后点击行恢复、方向键缩窄与双击恢复上限、历史追加到 42 个无重复请求；所有步骤行高为 36px，行右侧附加元素与内联详情数量为零。1500px 视口下右栏为 640px；1100px 与 1001px 视口下右栏分别为 554px 与 455px，中栏均保留 320px；900px 与 400px 视口回到文档流，没有页面横向溢出。
