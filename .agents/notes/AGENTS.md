# AGENTS.md — Agent Notes

Agent Note 是 Agent 写的决策记录（RFC）：持久保存 rationale、备选方案、后果与必需的验证。遵守 Agent Note 规则（[README.md](README.md)）与本仓库的文档标准（目标项目为 docs/AGENTS.md，kit 仓库内为模板 templates/docs-AGENTS.md）。

**每份新 Agent Note 都触发 supersession check。** 在活动树里搜索覆盖同一决策或机制的旧记录，判定完全或部分取代，并在同一变更里归档全部符合条件的 implemented 记录。部分取代保持活跃并交叉链接。

[`archived/`](archived/AGENTS.md) 下的文件是冻结的历史快照：永不编辑，也不得当作现行权威。
