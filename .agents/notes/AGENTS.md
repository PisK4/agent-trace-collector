# AGENTS.md — Agent Notes

Agent Note 是 Agent 写下的决策记录（RFC）：为什么这么做、考虑过哪些备选方案、带来什么后果、需要哪些验证，都长期保存在这里。写法遵守 Agent Note 规则（[README.md](README.md)）与本仓库的文档标准（目标项目是 docs/AGENTS.md；kit 仓库内用模板 templates/docs-AGENTS.md）。

**每份新 Agent Note 都要先做 supersession check。** 在活动树里搜索覆盖同一决策或机制的旧记录，判断它是被完全取代还是部分取代。完全取代的 implemented 记录在同一变更里归档；部分取代的原记录保持活跃，并和新记录互相链接。

[`archived/`](archived/AGENTS.md) 下的文件是冻结的历史快照：永不编辑，也不得当作现行权威。
