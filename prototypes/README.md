# Trace 阅读原型

原型评估单一的步骤轨迹界面。静态入口使用合成数据；本机入口在用户明确指定后只读已采集的数据，不连接 magpie。生产界面仍以 [`web/`](../web/) 为准。

在 collector 仓库根目录运行：

```sh
python3 -m http.server 8767 --bind 127.0.0.1 --directory prototypes
```

打开 [Trace 阅读原型](http://127.0.0.1:8767/trace-reader-prototype.html)。无需安装依赖。

本机真实数据入口要求 collector 已在默认 8320 端口运行，数据库和只读令牌位于默认数据目录：

```sh
bun prototypes/serve-local.ts
```

打开 `http://127.0.0.1:8768/?data=local&session=<会话前缀>&sample=first50`，展示该会话时间正序的前 50 条步骤。会话前缀必须唯一；页面明确提示后续内容未载入。省略 `sample` 时读取最近 30 笔请求并允许向前加载，省略 `session` 时列出最近 20 个会话。

服务只监听 127.0.0.1，SQLite 连接为 readonly 与 query_only，只代理现有 GET 读取接口，检查 Host、Origin 与同源请求。令牌留在服务进程，真实正文仅按需返回本机浏览器，不生成数据快照、fixture 或日志。真实数据模式不使用旧合成数据的上下文比较和计时图形，详情显示已读取片段与覆盖范围。

## 阅读与展开

中栏只保留连续单行步骤轨迹。每条用户消息、助手回复或工具调用占一行，请求序号、类型、摘要与展开箭头在同一水平线上，模型名和请求时刻放在右栏详情里。行首使用当前载入请求的顺序号 `1、2、3…`，同一请求的多条步骤共用数字，不是逐行步骤号或数据库 ID；追加历史会重新编号，展开状态仍按消息位置与工具位置保持。同一请求的首字、时长和输出速度显示在其最后一条步骤的右侧，只显示一次；用量和费用可在右栏查看。

本机右栏读数页按请求能力、请求结构、本次回复排列。工具与技能清单默认折叠；结构摘要显示总消息数和可信增量数，展开后每片读取最多 40 条原始消息，点击查看全文并可返回列表。新增关系未确认时不标新增，正文不可读时保留状态说明。本次回复完整显示，工具结果沿用已确认的结果路径读取。同请求加载和重绘保留右栏滚动与能力清单展开状态。

所有详情默认折叠。初始请求窗口按页面高度估算，至少载入 30 笔，当前主会话的 11 笔合成请求共形成 19 行，全部载入。历史超出窗口时，顶部显示加载更早记录按钮，每次追加一个窗口并保留阅读位置。记录从上到下按时间正序排列，回到最新按钮定位末笔请求。

步骤的展开箭头与选中操作独立，点击后在行下方显示全文或工具参数与结果；完整请求详情可继续原位展开上下文、路由与原始对象。会话、请求和请求详情标签写入 URL，刷新可恢复；窗口大小、面板宽度及展开状态保存在内存中，主题偏好保存在本机浏览器。

## 交互

- 左上按钮折叠会话栏，右上按钮收起详情栏。
- 桌面端拖动右侧分隔线调整详情宽度，双击恢复默认；聚焦分隔线后用左右方向键微调。
- 点击 Session ID 旁的复制图标复制完整 ID；剪贴板不可用时显示可选中的 ID。
- 右侧请求详情分为读数、正文、工具和路由；工具详情分为概览、参数、结果与 Schema。
- Bash 摘要显示命令，文件读取显示路径；多个调用分别展示。工具结果按调用 ID 在后续请求中匹配；关联未确认、结果未读取与读取失败目前在部分位置共用「未记录」文案，待[生产迁移计划 Task 0](../docs/superpowers/plans/2026-10-23-single-timeline-production-reader.md)分开。
- 通用口径说明默认折叠；失败、未完成、缺正文仍显示在相关记录上。

## 数据口径

一笔请求表示客户端的一次调用，网关内部的多 provider 尝试仍属同一笔。工具调用归属发起它的请求，结果可能出现在后续请求。模型请求计时与工具执行计时分开，演示未提供工具执行耗时，也不把结果已记录等同于工具成功。

`usage.in` 不含缓存读取与写入；提示总量为三者之和。首字到第一个内容，首个文本可以更晚，工具调用回复可以没有文本。上下文总量经上游校准，各类按估计比例分配；窗口未知时不显示占用率。静态入口的数值都是合成场景值；本机入口沿用 API 中的真实读数，缺失值保持缺失。

正文先转义再渲染少量 Markdown。完整上下文指保存的客户端协议对象，历史可能经过压缩、裁剪，不保证包含完整会话，也不代表各 provider 最终收到的输入。最新记录缺正文时保留身份与读数。完整请求详情中的新增内容筛选沿用合成数据比较逻辑，不能替代生产的前驱关系与增量派生。

## 验证范围

浏览器检查确认主会话载入 19 行，每行高度均为 36px，详情默认展开数为 0，列表没有模型名。展开助手详情可看到全文，收起后恢复单行。400px 窄屏检查中，文档宽度为 400px，行高仍为 36px，没有页面横向溢出。
