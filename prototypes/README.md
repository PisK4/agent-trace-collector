# Trace 阅读原型

一个会话一段对话：左侧列出全部会话并标出异常，主区按「对话 / 请求账本」两种方式读同一个会话，右侧固定显示当前 Request 的 Response 读数。全部使用合成数据，不连接 magpie，不读取真实会话。

在 collector 仓库根目录运行：

```sh
python3 -m http.server 8767 --bind 127.0.0.1 --directory prototypes
```

打开 [Trace 阅读原型](http://127.0.0.1:8767/trace-reader-prototype.html)。也可直接用浏览器打开 HTML，无需安装依赖。会话、选中请求、视图和右栏 Tab 写入 URL，刷新可恢复；其余交互保存在内存中。

## 三栏各回答什么

**左栏：有哪些会话。** 已归属会话与未归属请求分组列出，每条显示 Agent、请求数、最后一笔时间，以及「含失败 / 含未完成 / 待确认 / 缺正文」中优先级最高的一项。搜索匹配会话标题、Agent、session id 与请求标题；Agent 筛选是平铺按钮，不隐藏其它 Agent 的历史。

**中栏：这段对话发生了什么。**

- 「对话」是默认视图。按请求分段：每一段先显示该笔新增的 USER 消息，再显示该笔的 ASSISTANT 回复。工具调用收成单行 chip，结果在下一条请求的 messages 里按 `tool_call_id` 对回，可展开读原文。回复按极简 Markdown 渲染（表格、列表、行内 code），未支持的语法原样显示；所有内容先转义，不执行消息里的 HTML。
- 同一段对话里的工具往返各算一笔请求，所以会出现「这一笔没有新的用户消息，输入是上一笔的工具结果」。这是账本的真实结构，不是渲染缺陷。
- 「请求账本」把每笔请求收成一行：时间、标题、状态、回复首行、时长与用量。展开后读该笔的完整请求结构（按协议路径逐项）、本次回复、路由与尝试、协议对象。
- 结构表默认选中最后一条用户消息，点击任意行在右侧读全文；「仅本轮新增」按消息内容哈希与上一笔比较，是派生视图。
- 「在账本中查看 Request NN」把对话里的位置映射到账本行。

**右栏：这笔 Response 的参数。** 「读数」Tab 固定为五段：

1. 首字（TTFT）、总时长、输出速度三个大数；
2. 用量：输入（不含缓存）、输出、缓存读取、缓存写入、提示总量、费用、缓存命中比例；缺失显示「未报告」，不当作 0；
3. 时间构成：首字前 / 首字后生成的堆叠条，加首个文本的刻度；
4. 上下文组成：六类固定槽位的比例条与数值，窗口容量与占用；
5. 路由去向与数据完整性：请求模型、命中规则、实际去向、上游返回名、亲和性，以及正文 / 账本 / 路由三条通道各自的到位情况。

「正文」Tab 是协议路径的全文阅读器，可上下逐项翻阅。

## 数据口径

- 一笔请求 = 客户端的一次调用；工具往返各算一笔，magpie 内部的多 provider 尝试仍属同一笔，显示为尝试链。
- `usage.in` 不含缓存读取与写入；提示总量 = 三者之和，等于 `prompt.tokens`。演示数据已保证这一等式成立。
- `ttft` 是到第一个内容（文本、推理或工具调用）；`firstText` 是到第一个文本，所以工具调用请求可以没有文本、`firstText` 为空。
- `prompt` 的总量经上游校准，六类按估计比例分配；窗口未知时不显示占用率。
- 亲和性 `why=cache` 是发送前的保留决策，不代表本次已命中缓存。

## 完整性的边界

完整上下文指本次保存的客户端协议对象，并不保证包含完整会话原文。历史可能经过压缩、裁剪，或通过前序响应引用保存在上游。hook 观察点之后仍可能发生协议转换或改写，不能称为各 provider 的最终输入。

最新记录没有正文时，仍显示身份与读数以及缺失原因，不自动退回旧正文。direct、reported、窗口未知、用量未报告、关联歧义、回复 incomplete 与最终失败均有独立演示。上下文数值是合成场景值，不由短示例正文计量。

## 验证记录

已在 ego-browser 中实际打开并截图验收：1507×838 与 1200×900 的三栏布局、900px 与 400px 的纵向堆叠、深色与浅色两套表面、对话与账本切换、账本展开、仅本轮新增筛选、协议路径选中与方向键移动、会话内搜索只标记本次请求、URL 恢复、主题持久化。

检查过的数据不变量：每笔请求的 `in + cacheRead + cacheWrite` 等于 `prompt.tokens`，六类之和与之相等；`ttft < ms`，`firstText ≥ ttft`；失败请求没有首字；正文缺失的请求不显示伪造内容。窄屏三栏不再互相覆盖，横向滚动宽度等于视口宽度。

本机预览 HTTP 200，内联脚本通过语法检查。没有连接真实采集链路，也没有验证生产数据规模下的性能。Artifact 受当前 token 认证方式限制，使用本地预览。
